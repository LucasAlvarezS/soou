# Bienvenido a soou

Esta es una nota de ejemplo. Cada nota tiene **frontmatter** (metadatos entre `---`)
y un cuerpo en Markdown. Los enlaces `[[nombre]]` conectan notas y forman el grafo.

Para empezar tu propio cerebro:

1. Copia estos ejemplos a tu carpeta `wiki/` (o usa `soou.py` para capturar sesiones).
2. Escribe notas de UN concepto cada una, enlazando con `[[..]]`.
3. Busca con `python soou.py query "tu pregunta"`.

Este es el patrón [[llm-wiki]]. Explora también [[proyecto-ejemplo]].
